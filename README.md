# L4D2 音频库合并工具

求生之路 2（Left 4 Dead 2）音频库 mod 自动合并工具。把多个音频库（替换音效的 mod）合并成一个，
自动处理脚本冲突、音频文件去重，并支持打包成 l4n 平台可加载的单文件 VPK。

纯 Python 标准库开发，**无需安装任何第三方库**；普通用户直接下载 Release 里的 exe 即可，**不需要装 Python**。

## 功能

- **多库合并**：添加多个音频库文件夹，列表越靠上优先级越高，同名音效/文件以高优先级为准
- **冲突可视化处理**：
  - 脚本条目冲突（同一个音效名在多个库里定义）——可逐条点选采用谁
  - 音频文件冲突——可试听候选后决定采用谁
- **两种来源**：
  - 音频库文件夹（根目录含 `pak01_dir.vpk` 和 `sound/`）
  - 一键扫描游戏目录里已部署的库
- **自动检测游戏目录**：查注册表 Steam → C 盘默认位置 → 各盘符根目录浅层探测，扫不到可手动指定
- **三种导出形态**：
  1. **合并库文件夹**（传统部署方式，导出后附「使用方法.txt」）
  2. **l4n 独立包（VPK）**：音频库打包成单个 `<名字>+l4n.vpk`，需安装 l4n 平台
  3. **l4n 皮肤合体（VPK）**：把音频库直接合并进一个皮肤 mod VPK，一个文件同时带皮肤和音效
- **sound.cache 预生成**：检测到 l4n（`source_nekomimi.exe`）时，导出 VPK 可顺带生成 `sound.cache`，
  部署后进游戏无需再敲控制台命令
- **单文件 VPK**：l4n 包为不分卷的单文件 addon 布局；有官方 `vpk.exe` 时优先使用，否则用内置封包器

## 支持范围与限制

- 仅支持脚本全部位于 `scripts/` 目录下的音频库；`+Custom_Sounds` 类型（脚本放在自定义目录）**不支持**
- l4n 的 VPK 加载方式依赖 **l4n 插件平台**，未安装 l4n 时请用传统文件夹部署
- 皮肤 mod 若已自带 `l4n/` 目录，合并时会强制进行入口级脚本合并并给出警告

## 下载与使用（无需 Python）

exe 由 GitHub Actions 自动构建，有两个下载渠道：

**方式一：Releases 正式版（推荐普通用户，免登录）**

1. 打开 [Releases](../../releases)，下载最新版本里的 **`音频库合并工具.exe`**
2. 放到任意目录，双击即可运行，**无需安装 Python 或任何其他软件**

**方式二：Actions 最新构建（想第一时间用最新改动时）**

1. 打开 [Actions 构建页面](../../actions)，点最近一次绿色 ✓ 的 **Build & Release**
2. 页面底部 **Artifacts（产物）** → 下载 **`AudioMergeTool-exe`**（是个 zip，解压得到 exe）
3. 注意：Actions 产物需登录 GitHub 账号才能下载，且默认只保留 90 天

**通用提示：** Windows 可能报 SmartScreen 未知发布者 / 杀毒误报（PyInstaller 单文件打包的常见现象），
选择「仍要运行」或加白名单即可。

## 运行依赖说明（关键功能全部内置）

| 功能 | 实现方式 | 是否需要外部程序 |
|---|---|---|
| 读取/拆包 VPK（读音频库、读皮肤 mod） | 内置 VPK 解析器 | ❌ 不需要 GCFScape |
| 封包/写出 VPK（l4n 单文件包） | 内置封包器 | ❌ 不需要；游戏目录有官方 `vpk.exe` 时会优先借用，没有也照常出包 |
| 合并音频库 / 导出文件夹 | 纯内置 | ❌ 无任何依赖 |
| 预生成 `sound.cache`（仅 l4n 包导出时的可选项） | 调用 l4n 平台的 `source_nekomimi.exe` | ⚠️ 需游戏目录已装 l4n；没装则不显示该选项，传统文件夹导出完全不受影响 |

注：l4n 形态的 VPK 本身就只有安装了 l4n 平台的游戏才能加载，这是该 mod 形态的前提，
不是本工具的门槛；不使用 l4n 时，传统文件夹合并导出不需要游戏目录里有任何额外东西。

## 从源码运行（开发者 / 装有 Python 的用户）

要求 Python 3.8+（python.org 官网安装包默认自带 tkinter）：

```bat
git clone 本仓库后
python -m merger.gui
```

## 自行打包 exe

```bat
pip install pyinstaller
pyinstaller --onefile --noconsole --clean --paths . --name 音频库合并工具 merger/gui.py
```

打包结果在 `dist\音频库合并工具.exe`。本仓库推送 `v*` 开头的 git tag 时，
GitHub Actions 会自动在 Windows 环境打包并发布 Release，无需本地构建。

## 目录结构

```
merger/            源码
  core.py          游戏目录检测、库扫描、合并分析、导出
  vpk.py           VPK v1/v2 读取与单文件封包
  keyvalues.py     KeyValues 脚本解析/合并/序列化
  gui.py           Tkinter 界面
启动音频库合并工具.bat   启动器（优先 exe，回退 Python 源码）
音频库合并工具.exe       打包好的可执行文件（GitHub Actions 构建产物，仓库中不含）
```
